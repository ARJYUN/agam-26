# AGAM'26 — Annual Cultural Fest Website

## 1. Project Vision

Create a premium, immersive website for **AGAM'26**, the college's Annual Cultural Fest.

The visual identity should combine:

- **Modern interactive web design**
- **Classical Kerala cultural aesthetics**
- **Off-white / ivory visual language**
- **Elegant typography**
- **Dynamic movable artforms**
- **Subtle motion and parallax**
- **Traditional motifs used in a contemporary way**
- **Clean layouts with generous whitespace**
- **A sophisticated, artistic atmosphere rather than a typical college-event website**

The website should feel like **a living cultural canvas** where Kerala's artistic heritage interacts with a modern digital interface.

---

## 2. Core Design Direction

### Primary Theme

**Modern × Classical × Artistic**

The overall background should be a warm **off-white / ivory**, avoiding a pure white interface.

Suggested palette:

- Background: `#F8F4E8`
- Secondary background: `#F1EBDD`
- Deep text: `#25201A`
- Muted brown: `#705C45`
- Traditional red accent: `#9E3F32`
- Gold accent: `#B58A45`
- Soft green accent: `#65735A`

Use accent colours sparingly.

### Visual Language

Use:

- Fine ornamental borders
- Traditional Kerala-inspired patterns
- Organic curves
- Hand-drawn / engraved-style illustrations
- Classical decorative motifs
- Subtle paper/grain texture
- Thin elegant dividers
- Large editorial typography
- Asymmetric compositions
- Floating cultural illustrations

Avoid:

- Heavy gradients
- Neon colours
- Overly dark backgrounds
- Generic corporate cards
- Excessive glassmorphism
- Overcrowded layouts
- Cartoonish cultural illustrations

---

# 3. Global Motion System

Dynamic artforms should be present throughout the website, but motion must remain **elegant and controlled**.

### Floating Artform System

Create independent decorative elements that:

- Slowly float vertically
- Rotate slightly
- Move according to cursor position
- React subtly to scrolling
- Enter/exit sections with parallax
- Have different animation speeds
- Never obstruct important content

Possible floating cultural elements:

- Theyyam face / headpiece motifs
- Kathakali-inspired eye or face details
- Classical dance mudras
- Chenda
- Violin
- Flute
- Mridangam
- Traditional lamps
- Kerala mural motifs
- Temple ornament-inspired line art
- Floral motifs
- Brass ornament shapes
- Traditional percussion silhouettes

The elements should look like **artistic illustrations / engraved forms**, not realistic photographs.

### Motion Principles

- Slow floating: `8–15s`
- Small rotation: `-8deg to +8deg`
- Gentle parallax movement
- Ease-in-out transitions
- Scroll-triggered reveal animations
- No aggressive bouncing
- Respect `prefers-reduced-motion`

---

# 4. Website Structure

The website should contain the following major sections:

1. Hero
2. Countdown
3. Event Registration
4. Department-wise Leaderboard
5. Organizing Team
6. Footer

Every major section should contain at least one **dynamic decorative cultural element near a corner**.

---

# 5. HERO SECTION

## Objective

The hero should immediately communicate:

> **AGAM'26 — A Celebration of Art, Culture and Expression**

It should be the most visually impressive part of the website.

### Layout

Use a full-width desktop hero.

Suggested composition:

- Large AGAM'26 typography
- Short cultural tagline
- Fest date
- CTA buttons
- Large dynamic Theyyam-inspired artwork
- Floating classical art elements around corners
- Subtle ornamental framing

### Hero Copy

**AGAM'26**

**ANNUAL CULTURAL FEST**

> Where Tradition Finds a New Rhythm.

Supporting text:

> A celebration of art, music, dance, literature and the vibrant spirit of our campus.

CTA:

- `REGISTER NOW`
- `EXPLORE AGAM`

### Hero Artwork

The central/primary artwork should feature **Theyyam** as the main cultural visual.

The Theyyam artwork should be:

- Elegant
- Detailed
- Classical
- Slightly stylized
- Suitable for an off-white background
- Integrated into the composition instead of appearing like a pasted image

Do **not** use a boat or temple as the primary visual.

### Hero Animation

The Theyyam artwork can have:

- Slight floating movement
- Slow rotation of decorative ornaments
- Independent movement of feathers / ornaments
- Subtle parallax
- Cursor-reactive movement

### Hero Corner Decorations

Top-left:

- Small mural-inspired ornament

Top-right:

- Floating classical mudra illustration

Bottom-left:

- Small chenda / percussion illustration

Bottom-right:

- Floral / traditional ornament

All should move independently.

# 6. COUNTDOWN SECTION

The countdown should create anticipation for AGAM'26.

### Heading

**THE MOMENT APPROACHES**

Supporting text:

> The stage is set. The artists are ready. Are you?

### Countdown

Display:

- Days
- Hours
- Minutes
- Seconds

Use large editorial numerals.

Example:

```text
  21        08        42        17
 DAYS     HOURS     MINUTES    SECONDS
```

### Design

Use a minimal off-white layout with thin decorative borders.

Each countdown value can appear inside an elegant classical-inspired frame.

### Motion

- Numbers should update smoothly
- Subtle flip/count animation
- Decorative elements gently move around the section
- Small floral or mural motif in one corner
- A floating Theyyam ornament can enter from the opposite corner

### Layout

- Registration CTA

Right side:

- Dance
- Music
- Literary
- Fine Arts

Use a small moving musical instrument illustration at the bottom corner.

# 8. DEPARTMENT-WISE LEADERBOARD

## Objective

Create an exciting but elegant competitive section showing department standings.

### Heading

**THE CAMPUS RACE**

Supporting text:

> Every performance earns a point. Every point tells a story.

### Leaderboard

Display department rankings with:

- Rank
- Department
- Points
- Events participated
- Trend / movement

Example:

| Rank | Department | Points |
|------|------------|--------|
| 01 | CSE | 1840 |
| 02 | ECE | 1720 |
| 03 | ME | 1580 |
| 04 | CE | 1430 |

### Visual Style

Do not use a generic gaming leaderboard.

Instead:

- Use elegant ranking numbers
- Classical ornamental separators
- Subtle gold detailing for the top position
- Department initials as visual badges
- Animated score counters

### Interaction

Users should be able to:

- Filter by department
- View current score
- See ranking changes
- Expand a department to see event-wise points

### Motion

- Rank positions animate when updated
- Points count upward
- Small decorative particles move around the leaderboard
- A traditional ornament can slide around the section border

# 11. CORNER ART SYSTEM

A key identity feature of the website should be **dynamic corner art**.

Every major section should have decorative elements positioned near its corners.

Example:

```text
┌──────────────────────────────────────────────┐
│  ✦ floating motif                 mudra ✦   │
│                                              │
│                SECTION CONTENT               │
│                                              │
│  chenda ✦                       floral ✦    │
└──────────────────────────────────────────────┘
```

These elements should:

- Be partially outside the content container
- Move slowly
- Respond slightly to cursor movement
- Change position subtly with scrolling
- Maintain visual balance

The decorative elements must never make the website feel cluttered.

---

# 12. RESPONSIVE DESIGN

## Desktop

- Large hero composition
- Multiple floating artforms
- Asymmetric layouts
- Strong typography
- Wide decorative framing

## Tablet

- Reduce decorative elements
- Reduce parallax intensity
- Maintain asymmetric layouts where possible

## Mobile

- Stack content vertically
- Preserve the off-white aesthetic
- Keep 2–3 important floating art elements per section
- Reduce animation intensity
- Make buttons touch-friendly
- Keep typography highly readable

---

# 13. TYPOGRAPHY

Use a combination of:

### Display Font

A sophisticated serif / classical editorial font.

Purpose:

- AGAM
- Section headings
- Large numbers
- Important statements

### Supporting Font

A modern clean sans-serif.

Purpose:

- Navigation
- Buttons
- Body text
- Event details
- Leaderboard data

Optional accent:

A restrained Malayalam / Indic display typeface for small cultural labels.

Typography should feel:

**Editorial + Classical + Contemporary**

---

# 14. UI DETAILS

### Buttons

Use elegant pill or slightly rounded rectangular buttons.

Example:

`REGISTER NOW →`

Hover:

- Border expands
- Arrow moves
- Background subtly changes

### Dividers

Use:

- Thin ornamental lines
- Small central motifs
- Minimal flourishes

### Cards

Cards should have:

- Off-white / slightly darker paper-like background
- Thin border
- Soft shadow
- Rounded or softly curved corners
- Traditional decorative details

---

# 15. INTERACTION DETAILS

### Cursor

Optional custom cursor:

- Small circular dot
- Subtle traditional ornament trail

On hover over interactive elements:

- Cursor expands
- Small label appears

### Scroll

Use smooth scrolling.

Sections should reveal through:

- Fade
- Slide
- Mask reveal
- Parallax

Avoid excessive animation.

---

# 16. ACCESSIBILITY & PERFORMANCE

The design must remain performant.

Requirements:

- Respect `prefers-reduced-motion`
- Lazy-load heavy artwork
- Optimize images as WebP/AVIF
- Avoid excessive JavaScript animations
- Use CSS transforms where possible
- Keep text contrast accessible
- Ensure keyboard navigation
- Provide visible focus states
- Buttons must have accessible labels
- Do not rely only on colour to communicate ranking/status

---

# 17. OVERALL EXPERIENCE

The final website should feel like:

> **A Kerala cultural art exhibition transformed into an interactive modern website.**

The visitor should experience:

**Curiosity → Wonder → Cultural immersion → Participation → Competition → Community**

The design must never look like a generic college fest template.

The core visual idea is:

> **Traditional artforms floating through a modern digital canvas.**

The off-white background provides the canvas, classical Kerala art provides the soul, and dynamic motion provides the modern identity.
